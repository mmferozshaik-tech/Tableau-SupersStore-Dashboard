# Tableau-SupersStore-Dashboard

## 📌 Project Overview

Developed an interactive **Sales Dashboard using Tableau** with the **Sample Superstore dataset** to analyze sales, profit, orders, customers, products, and regional performance.

The dashboard provides interactive visualizations, KPIs, filters, parameters, and drill-down analysis to support data-driven business insights.

---

## 🎯 Objectives

* Analyze overall **Sales and Profit performance**
* Identify top-performing **Products and Categories**
* Compare performance across **Regions and States**
* Analyze **Sales and Profit trends over time**
* Identify high and low-performing products
* Provide interactive filtering for business analysis
